## ⚡ Quick Agent Commands

You can interact with your Personalized Agent using commands like:
- **`"Log today's activity: ..."`** → Appends a new timestamped log to `daily_logs.md`.
- **`"Add new interest: ..."`** → Updates `interests.md`.
- **`"Record experience: ..."`** → Adds a project/achievement to `experiences.md`.
- **`"Set active focus: ..."`** → Updates `active_context.md`.
- **`"Update profile / preference: ..."`** → Modifies `user_profile.md` / `system_patterns.md`.
